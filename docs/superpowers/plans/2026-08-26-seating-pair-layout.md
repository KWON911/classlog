# 자리 배치: 짝 자리/개별 자리 레이아웃 구현 메모

## 배경

현재 자리 배치는 행과 열만 지정하는 단순 격자다. `지난 짝 피하기`는 같은 행에서 오른쪽에 바로 붙은 학생을 모두 짝으로 판단한다.

따라서 실제 교실에 두 자리짜리 책상 묶음과 통로가 있는 경우에도, 통로 양쪽 학생이 짝으로 처리될 수 있다. 레이아웃을 명시하면 화면 표현과 지난 짝 피하기의 기준을 일치시킬 수 있다.

## 권장 UX

`자리바꾸기 설정`의 **Layout** 섹션 맨 위에 `자리 형태` 선택을 추가한다.

- `짝 자리` (기본값)
  - 가로로 붙은 두 좌석을 하나의 짝 묶음으로 본다.
  - 1–2열, 3–4열처럼 두 열마다 통로 여백 또는 구분선을 보여 준다.
  - `지난 짝 피하기`는 같은 묶음 안의 좌우 학생만 기준으로 삼는다.
- `개별 자리`
  - 모든 좌석을 독립 좌석으로 표현한다.
  - `지난 짝 피하기`는 비활성화하고, “짝 자리에서만 사용할 수 있습니다.”를 표시한다.

기본값을 `짝 자리`로 두면 기존 자리표의 현재 동작을 최대한 유지할 수 있다.

## 구현 범위

1. `src/lib/types.ts`
   - `SeatLayout = 'paired' | 'individual'` 타입 추가.
   - `SeatingPlan`에 `seat_layout` 필드 추가.

2. `supabase/schema.sql`
   - `seating_plans.seat_layout` 컬럼을 `not null default 'paired'`로 추가.
   - 기존 배포 DB를 위한 `alter table ... add column if not exists` 마이그레이션과 체크 제약 추가.
   - 기존 저장 기록은 기본값 `paired`로 자동 보완된다.

3. `src/routes/SeatingPage.tsx`
   - `seatLayout` 상태와 설정 UI 추가.
   - 개별 자리 선택 시 `avoidPastNeighbors`를 끄고 관련 안내 표시.
   - 자리표 저장·불러오기·복제 시 `seat_layout`을 함께 처리.

4. `src/lib/seating.ts`
   - `derivePastNeighborPairs(plans)`에 레이아웃 판단 추가.
   - `paired`일 때만 1–2열, 3–4열처럼 같은 두 열 묶음 안의 좌우 학생을 짝으로 기록한다.
   - `individual` 기록은 지난 짝 기록을 만들지 않는다.

5. `src/components/SeatingGrid.tsx`
   - `seatLayout` prop 추가.
   - `paired`일 때 두 열 단위로 시각적 구분(열 사이 여백 또는 옅은 세로 구분선)을 표시한다.
   - `individual`은 현재의 균일한 격자 표현을 유지한다.

6. 검증
   - `src/lib/seating.test.ts`에 짝 묶음 안의 좌우 학생만 기록되는지, 개별 자리는 기록하지 않는지 테스트 추가.
   - `npm test`, `npm run build`, 모바일·데스크톱 화면 확인.

## 구현 전 확인할 사항

- 짝의 방향은 기본적으로 **가로(좌우)**로 가정한다. 실제 교실에서 앞뒤 학생을 짝으로 보아야 한다면 기준을 바꿔야 한다.
- 짝 자리는 짝수 열에서 가장 자연스럽다. 홀수 열을 허용할 경우 마지막 열은 개별 자리로 표시한다.
- 개별 자리에서도 단순한 옆자리 회피가 필요하다면, `지난 짝 피하기`와 별도로 `지난 옆자리 피하기` 기능을 설계해야 한다.
