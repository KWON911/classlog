# 홈 주간 출결 요일 박스 → 출결관리 날짜 딥링크 설계

## 목표

홈 화면의 주간 출결에서 각 요일 박스의 빈 영역을 클릭하면 해당 날짜의 일일 출결 수정 화면으로 이동한다.

## 동작

- 요일 박스 전체를 클릭 가능한 요소로 만든다.
- 이동 주소는 `/attendance?date=YYYYMMDD`이며, 기존 `AttendancePage`의 날짜 쿼리 파싱을 재사용한다.
- 학생 출결 배지는 기존 주소(`/attendance?date=YYYYMMDD&student=<id>`)를 유지한다. 따라서 배지 클릭은 해당 학생 행의 강조와 자동 스크롤을 계속 제공한다.
- 배지 클릭 이벤트는 부모 요일 박스의 클릭으로 전파되지 않도록 막아, 학생 파라미터가 사라지지 않게 한다.

## 접근성 및 범위

- 요일 박스는 키보드로도 활성화 가능한 버튼으로 구현하고 날짜 기반 안내 레이블을 제공한다.
- 출결이 없는 주의 기존 빈 상태 UI, 출결 입력·저장 로직, 학생 배지의 표시 방식은 변경하지 않는다.

## 검증

- 날짜 딥링크 생성 순수 함수를 테스트해 빈 영역 이동 주소를 검증한다.
- 기존 출결 관리·홈 화면 관련 테스트, lint, production build를 실행한다.
