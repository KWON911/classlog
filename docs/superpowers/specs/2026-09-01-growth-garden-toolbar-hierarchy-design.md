# 성장정원 제어 영역 위계·정렬 통일 디자인

## 배경

성장정원은 정원, 월별 리포트, 설정, 개인 성장, 전체화면 정원, 수상 축하 화면으로 구성된다. 현재 공통 이동 탭은 재사용하지만, 정렬·보기·학생 선택·월 선택·학급/개인 전환이 화면별로 서로 다른 행과 좌우 위치에 있다. 특히 정원 화면은 카드 보기와 정원 보기 전환에 따라 `학생 선택` 유무가 바뀌어 표시 옵션 행의 위치가 달라질 수 있다.

## 목표

- 성장정원 모든 페이지에서 제어의 읽는 순서를 `이동 → 현재 화면 제어 → 콘텐츠 안의 동작`으로 통일한다.
- 데스크톱에서는 각 제어 행의 왼쪽 시작선과 오른쪽 주 동작의 끝선을 일관되게 맞춘다.
- 모바일에서는 좁은 폭에 서로 다른 역할의 버튼을 억지로 한 줄에 넣지 않고, 기능 묶음마다 독립 행을 사용한다.
- 기존 성장 기록, 점수, 선택, 리포트, 설정, 전체화면 동작과 데이터 접근 구조를 바꾸지 않는다.

## 공통 제어 행 규칙

### 데스크톱

```text
[정원 | 월별 리포트 | 설정]                         [현재 화면의 주 동작]
[현재 화면의 필터·정렬·보기 전환]                   [해당되는 보조 동작]
```

- 공통 이동 탭(`GardenPageNav`)은 항상 제어 영역의 첫 줄 왼쪽에 둔다.
- 해당 화면에서 즉시 시작하는 주 동작만 첫 줄 오른쪽에 둔다. 정원 목록의 `학생 선택`이 이에 해당한다.
- 필터·정렬·보기 전환처럼 표시 대상만 바꾸는 컨트롤은 둘째 줄 왼쪽에서 작업 순서대로 배치한다.
- 둘째 줄 오른쪽은 필요한 화면에서만 사용한다. 비어 있어도 왼쪽 제어 묶음의 시작 위치는 변하지 않는다.
- `전체화면 보기`는 전역 툴바가 아니라 전체화면 대상 장면의 제목 영역 오른쪽에 둔다.

### 모바일

```text
[정원 | 월별 리포트 | 설정]
[현재 화면의 주 동작]
[현재 화면의 필터·정렬·보기 전환]
```

- 공통 이동, 주 동작, 표시 제어를 각각 독립 행으로 둔다.
- 카드/정원 보기, 선택 모드처럼 조건부 컨트롤이 나타나거나 사라져도 다른 제어 묶음의 행과 시작선은 바뀌지 않는다.
- 정렬·보기처럼 함께 비교해야 하는 분절형 버튼은 한 묶음으로 유지한다.

## 화면별 적용

### 정원 목록 (`/growth-garden`)

- 첫 줄 왼쪽은 `GardenPageNav`, 오른쪽은 카드 보기·선택 모드 비활성일 때의 `학생 선택`이다.
- 둘째 줄 왼쪽은 `번호순 | 점수순`, 이어서 `카드 보기 | 정원 보기`다.
- 정원 보기에서는 `학생 선택`을 표시하지 않아도 둘째 줄은 같은 위치에 유지한다.
- 선택 모드의 전체 선택·해제·상점·벌점·종료는 카드 격자 바로 위 `SelectionActionBar`에 유지한다. 이는 선택 대상과 바로 연결된 콘텐츠 동작이므로 전역 제어 행으로 옮기지 않는다.
- 학급 전체 기록 초기화는 목록 맨 아래의 위험 동작으로 유지한다.

### 월별 리포트 (`/growth-garden/report`)

- 첫 줄 왼쪽에 `GardenPageNav`를 둔다.
- 둘째 줄 왼쪽에는 `월 선택`, 다음에 `학급 | 개인`을 둔다.
- 수상·보상 생성, 축하 보기, 삭제는 각 결과 카드 안에 유지한다. 전역 이동 또는 기간 제어와 섞지 않는다.

### 성장 기준 설정 (`/growth-garden/settings`)

- 제목 아래 첫 제어 행 왼쪽에 `GardenPageNav`를 둔다.
- 개인 식물·학급 정원 기준 카드의 저장과 기본값 복원은 해당 카드의 제목/하단 영역에 둔다.
- 기준 편집은 전역 이동과 독립된 카드 내부 동작으로 유지한다.

### 개인 성장 (`/growth-garden/:studentId`)

- 상단 왼쪽의 `학급 성장정원` 돌아가기 링크는 페이지 뒤로가기 역할로 유지한다.
- 상점·벌점은 식물, 점수, 진행도 바로 아래에 주 동작으로 유지한다.
- 기록 삭제, 전체 기록 보기, 전체 초기화는 최근 기록 카드 내부에 유지한다.

### 정원 전체화면과 수상 축하 화면

- 전체화면 전환은 해당 정원 또는 축하 장면 제목 영역의 오른쪽 끝에 둔다.
- 전체화면 종료와 닫기는 동일한 제목 영역에서 서로 인접한 보조 동작으로 유지한다.
- 일반 페이지의 이동·필터 툴바를 전체화면 장면에 복제하지 않는다.

## 구현 경계

- `GardenPageNav`와 기존 `SegmentedGroup`/`SegmentedButton`을 재사용한다.
- 제어 행의 정렬·줄바꿈 규칙은 공통 레이아웃 컴포넌트로 추출할 수 있으나, 단순한 클래스 조정만으로 중복 없이 적용할 수 있으면 새 추상화를 만들지 않는다.
- `GrowthGardenBoard`, `GrowthGardenReportPage`, `GrowthGardenSettingsPage`, `GrowthGardenStudentPage`, `GardenView`, `MonthlyAwardCelebration` 이외의 성장 데이터·서비스·Supabase 코드는 수정하지 않는다.
- 키보드 순서는 화면의 시각 순서와 동일하게 유지한다. `aria-current`, `aria-pressed`, 기존 레이블은 보존한다.

## 검증

- 데스크톱과 모바일 폭에서 정원 목록의 카드/정원 전환 전후에 정렬·보기 묶음의 행과 왼쪽 시작선이 같은지 확인한다.
- 정원 목록, 월별 리포트, 설정에서 공통 이동 탭이 각 제어 영역의 첫 줄 왼쪽에 있는지 확인한다.
- 월 선택 → 학급/개인 전환, 학생 선택 모드, 상점/벌점, 전체화면 전환, 설정 저장·복원, 개인 기록 동작을 회귀 확인한다.
- 관련 컴포넌트 테스트, TypeScript 검사, lint, production build를 실행한다.

## 범위 제외

- 성장 기록·점수·단계·꽃·리포트 계산 로직 변경
- Supabase 스키마·RLS·migration 변경
- 버튼 문구, 색상 체계, 아이콘의 전면 교체
- 학급 성장정원 밖의 앱 전역 사이드바 또는 다른 기능 화면 재설계
