# 학급 공동 목표·정원 장식 해금 설계

## 목적

개인 식물 성장과 별개로, 교사 한 명의 현재 학생 명단이 함께 쌓은 월간 상점 점수로 정원 장식을 해금한다. 개인 기여도·순위·경쟁 요소는 표시하지 않는다. 월별 진행도는 새로 시작하지만, 한 번 해금한 장식은 이후 점수 하락·기록 취소·월 변경에도 유지된다.

## 범위와 비범위

- 월별 목표 설정, 상점 기반 진행도, 자동 해금, 누적 장식, 정원/전체화면 표시, 월별 학급 리포트를 추가한다.
- 장식 6종 이상을 기존 SVG 스타일의 벡터 컴포넌트로 제공한다.
- 학생 투표, 개인별 기여도·순위, 동일 장식 다중 배치, 보상 데이터와의 통합은 만들지 않는다.
- 기존 개인 성장점수, 월간 성장값, 수상·보상, 식물/꽃 사이클 계산은 바꾸지 않는다.

## 데이터 모델과 RLS

`class_goals`는 교사·연월별 목표 한 건을 보관한다.

| 필드 | 의미 |
| --- | --- |
| `id` | 목표 ID |
| `teacher_id` | 소유 교사, `auth.uid()` |
| `year`, `month` | 목표 월 |
| `target_point` | 최종 목표 점수 |
| `milestones` | 3~5개의 `{ point, decorationType }` JSON 배열 |
| `created_at`, `updated_at` | 생성·수정 시각 |

`class_garden_unlocks`는 영구 해금 이력이다.

| 필드 | 의미 |
| --- | --- |
| `id` | 해금 ID |
| `teacher_id` | 소유 교사, `auth.uid()` |
| `decoration_type` | 장식 타입 |
| `year`, `month` | 해금된 목표 월 |
| `milestone_point` | 해금 기준 점수 |
| `unlocked_at` | 해금 시각 |

- `(teacher_id, year, month, milestone_point)`과 `(teacher_id, decoration_type)`을 고유하게 둔다. 전자는 동시 재계산의 중복 해금을, 후자는 같은 장식의 학기 중 재해금을 막는다.
- 두 테이블에는 기존 `teacher_id = auth.uid()` 소유권 RLS를 추가한다. 해금은 BehaviorRecord나 Reward와 분리한다.
- 별도 class/roster 테이블이 없는 현재 구조에 맞춰, 로그인 교사의 현재 `students` 명단을 하나의 학급으로 본다.

## 점수·해금 규칙

- 공동 목표 점수는 선택 월의 로컬 시각 `[월초 00:00, 다음 월초 00:00)` 범위에서, 현재 학생 소유 `growth_points`의 `type = merit`인 `amount` 합계다.
- `demerit`은 차감하지 않으며, `source = bulk` 기록도 포함한다.
- 점수는 저장된 누적값이 아니라 서비스가 기록에서 파생한다.
- 목표 저장 시 milestone 수는 3~5개, 점수는 양의 정수·엄격한 오름차순, 마지막 milestone은 `target_point` 이하이며 중복 장식은 허용하지 않는다.
- 진행도 계산 때 현재 점수가 milestone 이상이고 해당 장식이 아직 전역 해금되지 않았다면 해금 행을 idempotent하게 생성한다.
- 기록 삭제·일괄 취소로 점수가 내려가도 이미 생성된 해금 행은 삭제하지 않는다. 목표가 없는 달에는 점수/해금 연산을 하지 않고 설정 안내만 보인다.

## 서비스와 상태 경계

- `GrowthGardenService`에 월별 목표 조회·저장, 전체 해금 목록 조회, 해금 upsert, 월별 merit 합계 조회를 추가한다.
- Supabase와 mock 구현체가 동일 계약을 구현한다. UI와 hooks는 Supabase를 직접 호출하지 않는다.
- `useClassGardenGoal(year, month)` 훅은 목표, 해당 월 점수, 현재 달에서 해금된 장식, 누적 장식, 다음 milestone, 완료 상태를 조합한다.
- 개별·일괄 성장 기록 저장/삭제 성공 뒤 `useGrowthGarden`이 기존 리프레시 흐름에서 공동 목표를 다시 계산하고 새 해금을 시도한다. 해금 실패는 기록 저장을 되돌리지 않고, 목표 패널에 재시도 가능한 오류로 표시한다.

## UI와 시각 표현

- 정원 화면에 `우리 반 공동 목표` 패널을 추가한다. 월, `현재 / 최종 점수`, 진행 막대, 다음 장식·남은 점수, milestone 완료 상태를 보여준다.
- 목표가 없는 현재 월에는 "이번 달 공동 목표를 설정해보세요"와 설정 이동 버튼을 표시한다.
- 새 해금은 `GrowthFeedbackToast` 패턴을 재사용해 학급 전체 성취 문구와 장식명을 알리고, 장식은 0.6~1초 fade/약한 scale로 등장한다.
- `GardenDecorationLayer`는 학생 그리드 뒤·배경 위에 고정 슬롯으로 배치한다. `pointer-events: none`, reduced-motion 대응, 반응형/전체화면 크기 제한을 적용한다.
- 초기 타입은 `stone_path`, `bench`, `pond`, `birdhouse`, `big_tree`, `bridge`, `fence`, `garden_lamp` 중 최소 여섯 종류를 지원한다. 장식별 슬롯은 식물·이름을 가리지 않는 중앙 통로, 하단 모서리, 뒤쪽 가장자리로 고정한다.
- 전체화면은 정원 중심을 유지하며 작은 월·점수 표기만 남긴다.

## 설정·리포트

- 기존 성장 기준 설정 화면에 `학급 공동 목표` 카드를 추가한다. 연·월 선택, 최종 목표, milestone 추가/삭제(3~5개), 장식 선택, 저장을 제공한다.
- 이전 달을 저장·조회할 수 있으며, 다른 달의 설정을 덮어쓰지 않는다.
- 월별 학급 리포트는 해당 월의 목표, 최종 점수, 그 달 해금한 장식, 미달성 milestone을 보조 섹션으로 표시한다.

## 오류 처리와 접근성

- 잘못된 milestone·중복 장식은 저장을 막고 한국어 오류를 표시한다.
- RLS/네트워크 오류는 목표 저장, 해금, 조회 상태별로 표시한다.
- milestone 상태는 색상만으로 구분하지 않으며 텍스트와 아이콘을 함께 사용한다. 모든 선택·저장 제어는 키보드 접근과 충분한 터치 영역을 유지한다.

## 검증

- 순수 로직: 월 경계, merit만 합산, bulk 포함, demerit 제외, milestone 검증, 다음 상태, 완료 상태를 테스트한다.
- 서비스/훅: 목표 저장, 과거 월 격리, 해금 중복 방지, 이미 해금된 장식 재선택 방지, 점수 하락 후 해금 유지, 일괄 취소 반영을 테스트한다.
- 컴포넌트: 설정 유도, 진행 패널, 장식 레이어, 전체화면, 리포트 상태를 테스트한다.
- 기존 개별/일괄 상벌점, 개인 성장·사이클·꽃 도감, 정원/전체화면/자연 애니메이션, 성장 기준, 월별 리포트·수상·축하 화면을 회귀 확인한다.
- TypeScript, lint, 전체 테스트, production build를 실행한다.
