# 출결관리 - 월간요약 UI 재설계

## 배경

`/attendance` 페이지의 "월간 요약" 탭(`MonthlyAttendanceSummary`)이 촘촘한 표 형태에 색 없는 숫자 나열, 좁은 클릭 영역(화살표만 펼치기 가능) 등으로 가독성이 떨어진다는 피드백을 받았다. 사용자가 지적한 문제 5가지 — 전체 색상, 밀도/여백, 결석·지각·조퇴·결과 숫자 표시 방식, 펼치기/상세보기 상호작용, 상단 필터/버튼 영역 — 를 모두 해결하는 재설계.

브라우저 기반 시각적 브레인스토밍 companion으로 3가지 레이아웃 옵션(A: 카드형 리스트, B: 촘촘한 표 개선판, C: 상단 통계+리스트)을 시안으로 보여주고, 사용자가 **A + C 조합**을 선택했다.

## 범위

**포함**
- 학급 전체 이번 달 결석/지각/조퇴/결과 합계를 보여주는 상단 통계 카드 4개 추가
- 기존 표 행(`<tr>` 유사 구조)을 여백 있는 카드형 행으로 전환
- 상태 숫자를 색깔 뱃지(pill)로 표시, 0건은 회색 톤으로 낮춰 표시
- 카드 전체를 클릭 영역으로 확장(기존엔 화살표/텍스트 영역만 클릭 가능했음)
- 기존 필터 세그먼트("전체 N / 기록 있음 N"), "모두 펼치기" 버튼, 상세 기록 삭제 기능은 유지

**제외**
- 데이터 모델/훅 변경 없음 — `useAttendance(yearMonth)`가 이미 반환하는 `entries`/`students`만으로 집계
- 일일 출결 탭(`DailyStudentAttendance`), 캘린더(`AttendanceCalendar`)는 변경하지 않음
- 상세 기록의 인라인 수정 기능 추가 없음(기존과 동일하게 삭제만 가능)

## UI / 동작

### 1. 상단 학급 전체 통계 카드

필터 세그먼트 위, 페이지 상단에 4개의 통계 카드를 가로로 배치한다.

```
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│ 결석      │ │ 지각      │ │ 조퇴      │ │ 결과      │
│   2      │ │   5      │ │   1      │ │   1      │
└──────────┘ └──────────┘ └──────────┘ └──────────┘
```

- 값은 현재 `entries`(선택된 월 전체) 중 해당 상태의 건수 합계
- 카드 배경/텍스트 색은 `ATTENDANCE_STATUS_COLOR_CLASS`의 색 계열을 그대로 사용(결석=red, 지각=amber, 조퇴=purple, 결과=teal) — 톤만 카드용으로 살짝 진하게 조정
- 모바일에서는 2열 그리드로 줄바꿈

### 2. 필터 세그먼트 + 모두 펼치기 (기존 유지, 위치만 통계 카드 아래로)

기존 "전체 N / 기록 있음 N" 토글과 "모두 펼치기/모두 접기" 버튼은 그대로 유지한다. 로직 변경 없음.

### 3. 학생 카드 리스트

기존의 `StudentSummaryRow`(얇은 한 줄)를 카드형으로 재작성한다.

**기록이 있는 학생:**
```
┌─────────────────────────────────────────────────┐
│ (7) 이준호              결석0 지각0 조퇴1 결과1  ⌃│
├─────────────────────────────────────────────────┤
│ 🗑  8/12  [조퇴]  병원 진료                       │
│ 🗑  8/19  [결과]  가정학습                        │
└─────────────────────────────────────────────────┘
```
- 번호는 원형 뱃지(브랜드 컬러 톤)로 표시
- 상태 4종은 항상 모두 표시하되, 값이 0인 항목은 회색/저채도 뱃지로, 값이 있는 항목은 해당 상태 색으로 강조 — "0건도 한눈에 스캔 가능 + 실제 있는 값은 바로 눈에 띔"을 동시에 만족
- 카드 전체가 버튼(클릭 영역) — 기존처럼 우측 화살표 부분만이 아니라 카드 어디를 눌러도 펼침/접기 토글
- 펼쳤을 때 카드 하단에 날짜/상태뱃지/사유/메모/삭제 버튼 상세 행을 나열 (기존 `DetailRecord`의 정보 구성 그대로 재사용, 카드 안쪽 여백만 조정)

**기록이 없는 학생:**
```
┌─────────────────────────────────────────────────┐
│ (9) 최다인                              기록 없음│
└─────────────────────────────────────────────────┘
```
- 뱃지 없이 "기록 없음" 텍스트만, 카드 톤을 살짝 낮춰(연한 배경) 시각적으로 구분, 클릭 불가(기존과 동일)

### 4. 색상 원칙

- 상태별 뱃지/카드 색상은 기존 `src/lib/utils/attendanceStatusColors.ts`의 `ATTENDANCE_STATUS_COLOR_CLASS`를 단일 소스로 계속 사용 — 캘린더, 일일출결과 색상이 어긋나지 않도록 함
- 0건 표시용 회색 톤 클래스(`ATTENDANCE_ZERO_COUNT_COLOR_CLASS` 같은 이름)는 `attendanceStatusColors.ts`에 같은 파일 내 상수로 추가 — 상태별 색과 함께 한 곳에서 관리해 두 화면(캘린더/월간요약)이 갈라지지 않게 함

### 5. 반응형

카드 구조 자체가 좁은 화면에 자연스럽게 쌓이므로, 기존처럼 `hidden md:grid` / `md:hidden` 두 벌의 마크업을 유지할 필요가 줄어든다. 상태 뱃지 그룹에 `flex-wrap`을 적용해 좁은 화면에서 자동 줄바꿈되게 한다. 상세 기록 행도 카드 폭에 맞춰 자연스럽게 줄바꿈되도록 한다.

## 상태 관리 / 데이터

새 데이터 페칭 없음. 기존 `summaryByStudent`, `recordCountByStudent`, `entriesByStudent` 파생 데이터(`useMemo`)를 그대로 재사용한다. 상단 통계 카드용 합계만 새로 추가:

```ts
const classTotals = useMemo(() => {
  const totals: CountRow = { 결석: 0, 지각: 0, 조퇴: 0, 결과: 0 }
  for (const entry of entries) {
    totals[entry.status] += 1
  }
  return totals
}, [entries])
```

`filterMode`, `expandedStudentIds`, `deleteTarget`, 삭제 확인 모달(`AttendanceDeleteConfirmModal`), `deleteEntry` 호출 흐름은 모두 기존과 동일하게 유지 — 순수하게 마크업/스타일 계층만 재작성한다.

## 영향받는 코드

- `src/components/MonthlyAttendanceSummary.tsx`: 전면 재작성(마크업/스타일). `StudentSummaryRow`를 카드형으로, 상단에 통계 카드 섹션 추가, `AttendanceCounts`를 뱃지 렌더링으로 교체.
- `src/lib/utils/attendanceStatusColors.ts`: 0건용 회색 뱃지 클래스 상수 추가.
- 데이터 훅(`useAttendance`), `AttendanceDeleteConfirmModal`, `AttendancePage.tsx`의 탭 전환 로직은 변경 없음.

## 테스트

이 작업은 컴포넌트(`src/components/`)의 마크업/스타일 변경으로, 프로젝트 컨벤션상 자동화 테스트 대상이 아니다(순수 로직/훅만 테스트, 컴포넌트는 `npm run build` + `npm run lint` + 수동 스모크 테스트로 검증).

수동 확인 항목:
- 상단 통계 카드 4개의 합계가 학생별 카드 합계와 일치하는지(교차 검증)
- 기록이 있는 학생 카드를 클릭했을 때 카드 전체 어디를 눌러도 펼침/접기가 토글되는지
- 값이 0인 상태 뱃지와 값이 있는 상태 뱃지가 시각적으로 구분되는지
- "전체 / 기록 있음" 필터, "모두 펼치기/접기" 버튼이 기존과 동일하게 동작하는지
- 상세 기록의 삭제 버튼 클릭 → 확인 모달 → 삭제까지 기존 플로우가 그대로 동작하는지
- 좁은 화면(모바일 너비)에서 카드와 뱃지가 깨지지 않고 자연스럽게 줄바꿈되는지
- 기록 없는 학생 카드가 클릭되지 않고(비활성), 시각적으로 톤이 낮게 표시되는지
