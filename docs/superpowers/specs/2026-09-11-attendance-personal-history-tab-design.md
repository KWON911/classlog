# 출결관리 개인별 이력 탭 설계

## 목표

학생 누가기록 화면에서 출결 통계와 출결 이력 진입을 제거하고, 출결관리 안에서 학생별 누적 출결 이력을 조회한다.

## 화면과 동작

- `/attendance`의 상위 탭은 `일일 출결`, `월간 요약`, `개인별 이력` 순서로 둔다.
- `개인별 이력` 탭에는 학생 선택 드롭다운과 상태 필터(전체, 결석, 지각, 조퇴, 결과)를 둔다.
- 학생을 선택하면 해당 학생의 전체 기간 출결 예외를 최신 날짜순으로 표시한다. 기본 상태 필터는 `전체`다.
- 학생을 선택하지 않은 초기 상태에는 학생을 선택하라는 안내만 보이고 출결 행을 조회하지 않는다.
- 기존 상태별 직접 URL(`/attendance?view=history&student=...&status=...`)은 새 탭으로 호환 처리한다. URL의 학생·상태를 초기 선택값으로 사용하되, 별도 전용 화면은 렌더링하지 않는다.
- 학생 누가기록(`/students/:id`)에서는 출결 집계 배지, 출결 오류 메시지, 출결 전용 훅을 모두 제거한다.

## 구조

- `useStudentAttendanceHistory(studentId, status?)`는 학생이 선택됐을 때 `attendance`를 최신순으로 조회한다. 상태가 없으면 상태 조건을 추가하지 않는다.
- `StudentAttendanceHistory`는 학생 선택 상태에 따라 안내 또는 이력 목록을 표시한다. 출결관리 페이지가 학생·상태 선택 UI와 훅의 데이터를 전달한다.
- 기존 일일 입력·월간 요약, 저장·수정·삭제 경로와 NEIS 일정 연동은 변경하지 않는다.

## 검증

- 학생 상세에는 출결 요약이 렌더링되지 않는다.
- 개인별 이력 탭 선택, 상태 필터가 있는 전체/상태별 조회, 레거시 URL의 새 탭 연결을 라우트 테스트로 검증한다.
- 훅은 상태가 있을 때만 상태 조건을 적용하는지 검증한다.
