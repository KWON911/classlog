# 통합 출결 요약 설계

## 목표

`월간 요약`과 `개인별 이력`을 하나의 `출결 요약` 탭으로 합치고, 기간 필터로 월별 현황과 전체 누적 현황을 전환한다.

## 화면

- 출결관리 최상위 탭은 `일일 출결`, `출결 요약` 두 개다.
- 출결 요약은 `선택 월`, `전체 누적` 기간 버튼을 둔다.
- 두 기간 모두 학생별 카드 목록, 상태별 횟수 뱃지, 카드 펼치기, 기록 있음 필터를 공통으로 사용한다.
- 선택 월에서만 월 이동, NEIS 미입력 필터, 기록 삭제, NEIS·증빙서류 토글을 보인다.
- 전체 누적은 전체 기간 기록을 최신순으로 펼쳐 보이는 읽기 전용 화면이다.

## 데이터

- 월별 화면은 기존 `useAttendance(yearMonth)`를 유지한다.
- 전체 누적은 `useAllAttendance(enabled)`가 `attendance` 행 전체를 최신순으로 읽는다. 출결 요약의 전체 누적 모드에서만 요청한다.
- 기존 학생별 이력 훅과 단일 학생 이력 컴포넌트는 이 통합 화면으로 대체한다.
