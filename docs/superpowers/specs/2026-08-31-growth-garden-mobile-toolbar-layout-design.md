# 성장정원 모바일 툴바 정렬 개선 디자인

## 배경

모바일 성장정원 화면에서 `학생 선택` 버튼이 정렬 토글과 같은 줄을 차지하면서 보기 모드 토글이 다음 줄로 밀린다. 그 결과 `번호순/점수순`과 `카드 보기/정원 보기`가 서로 다른 줄에 놓여 표시 옵션의 관계가 흐트러진다.

## 목표

- 모바일에서 `학생 선택` 버튼을 정렬·보기 토글 바로 윗줄에 둔다.
- 정렬 토글과 보기 모드 토글을 그 아래 한 줄에 나란히 유지한다.
- 작은 화면에서도 둘째 줄이 줄바꿈되거나 가로 스크롤되지 않게 한다.
- 선택 모드 진입, 정렬, 보기 전환의 기존 동작과 접근성 라벨은 바꾸지 않는다.
- 태블릿과 데스크톱의 기존 배치를 유지한다.

## 모바일 레이아웃

```text
[정원 | 월별 리포트 | 설정]
[학생 선택]
[번호순 | 점수순]  [카드 보기 | 정원 보기]
```

첫째 줄은 화면 이동, 둘째 줄은 작업 시작, 셋째 줄은 표시 방식을 담는다. 페이지 이동 탭과 학생 선택을 같은 줄에 두면 390px 폭에서 둘 다 온전히 보일 수 없으므로, 학생 선택을 표시 옵션 바로 위에 둔다.

## 구현 방향

`GrowthGardenBoard`의 툴바를 페이지 이동, 학생 선택, 표시 옵션 행으로 구분한다. 모바일에서는 세 행이 위에서 아래 순서로 놓이고, `sm` 이상에서는 기존처럼 한 줄로 합쳐질 수 있게 반응형 flex 규칙을 사용한다.

둘째 줄은 `flex-nowrap`을 적용한다. `SegmentedGroup`과 `SegmentedButton`은 모바일에서 좌우 패딩과 간격을 줄이고 `sm` 이상에서 기존 여백을 복원한다. 텍스트와 아이콘은 유지하며 버튼 높이도 기존 `h-9`를 유지한다.

## 상태별 동작

- 카드 보기·선택 모드 비활성: 페이지 이동 행 아래, 표시 옵션 행 위에 `학생 선택`을 표시한다.
- 선택 모드 활성: 기존과 동일하게 상단 툴바의 표시 옵션을 숨기고 카드 격자 위 `SelectionActionBar`를 표시한다.
- 정원 보기: `학생 선택`을 표시하지 않고 정렬·보기 토글을 한 줄로 유지한다.
- 학생이 없을 때: `학생 선택`은 기존처럼 비활성화한다.

## 검증

- 모바일 뷰포트에서 `학생 선택`이 표시 옵션 바로 위에 보이는지 확인한다.
- 모바일 뷰포트에서 정렬·보기 토글이 셋째 줄 한 줄에 모두 보이는지 확인한다.
- 선택 모드 진입과 종료, 번호순·점수순, 카드 보기·정원 보기 전환을 확인한다.
- 프로덕션 빌드, 린트, 전체 테스트를 실행한다.

## 범위 제외

- 버튼 문구, 색상, 아이콘 변경
- 성장정원 카드 또는 선택 액션 바 디자인 변경
- 태블릿·데스크톱 툴바의 시각적 재설계
