# 정보관리 학생 상세 패널 설계

## 목표

정보관리의 학생 목록에서 학생별 상세정보를 확인하기 위해 관리 메뉴를 거치는 흐름을 없애고, 선택한 학생의 정보를 같은 화면에서 빠르게 확인·수정한다.

## 선택한 방향: 선택형 상세 패널

- 데스크톱과 iPad의 넓은 화면에서는 학생 명단 칩 영역과 선택 학생의 상세 패널을 나란히 표시한다.
- 학생 칩을 누르면 선택 상태를 표시하고, 상세 패널은 해당 학생의 출석번호·성별·연락처·주소·보호자·비고를 즉시 표시한다.
- 아무 학생도 선택하지 않았을 때는 학생 선택 안내를 표시한다.
- 상세 패널 상단에는 선택 학생을 편집하는 `수정` 버튼을 둔다. 기존 편집 모달과 저장 흐름을 재사용한다.
- 삭제는 상세 패널 하단의 구분된 위험 영역에 둔다. 확인 대화상자와 삭제 동작은 기존 흐름을 재사용한다.
- 학생 행의 `⋮` 관리 메뉴와 그 안의 상세정보 보기·수정·삭제 항목은 제거한다.
- 모바일에서는 목록 폭을 침범하지 않도록 학생 칩을 누를 때 동일한 상세 내용을 하단 시트로 연다. 수정·삭제의 위치와 의미는 데스크톱 패널과 동일하게 유지한다.

## 범위와 데이터 흐름

- 학생 데이터, 조회·수정·삭제 훅, `StudentDetailModal`, `StudentForm`, `ConfirmDialog`를 재사용한다. Supabase 접근 구조와 데이터 모델은 바꾸지 않는다.
- 선택 상태는 학생 목록 카드 내부의 `selectedStudent`로 관리하고, 학생 수정 또는 삭제 후 선택 상태가 오래된 데이터를 가리키지 않도록 갱신 또는 해제한다.
- CSV 가져오기·내보내기, 개별 학생 추가, 로딩·빈 상태·오류 상태는 변경하지 않는다.

## 검증

- 학생 칩 선택 시 상세 정보와 수정·삭제 제어가 표시되는 컴포넌트 테스트를 추가한다.
- 수정·삭제 실행 경로가 기존 콜백을 계속 호출하는지 확인한다.
- 대상 테스트, lint, production build를 실행하고 데스크톱·iPad·모바일 폭에서 상세 화면 전환을 수동 확인한다.
