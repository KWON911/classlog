# 누가기록 폼 동작 버튼 정렬 디자인

## 목표

누가기록 입력 폼 안의 `기록 저장`과 `취소` 버튼을 오른쪽에 정렬해 저장 동작 영역을 명확히 한다.

## 결정

- `RecordForm` 하단 버튼 그룹을 모든 화면 크기에서 오른쪽 정렬한다.
- 버튼 순서는 현재와 같이 `기록 저장`, `취소`를 유지한다.
- 버튼 문구, 제출·취소 동작, 폼 간격과 데이터 저장 경로는 변경하지 않는다.

## 검증

- `RecordForm`을 쓰는 학생 기록 작성·수정 화면에서 두 버튼이 같은 오른쪽 정렬 그룹으로 렌더링되는지 확인한다.
- lint와 production build를 실행한다.
