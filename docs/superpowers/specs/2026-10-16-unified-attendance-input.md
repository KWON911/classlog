# 출결 입력 통합

- 일일 출결의 전체 학생 목록과 ‘예외 학생만 보기’ 필터를 제거한다. 당일 기록이 있는 학생만 조회하고 수정·삭제한다.
- ‘출결 입력’에서 학생 검색·선택, 상태(결석/지각/조퇴/결과), 시작일·종료일, 구분, 공통 메모를 입력한다.
- 시작일과 종료일이 같으면 하루 입력이다. 기간이 다르면 최대 31일 범위에서 평일을 표시하고, 확인된 휴업일과 체크 해제한 날짜를 제외한다.
- 현재 월만 학사일정이 조회되는 기존 제약을 안내한다. 수업일이 아닌 날짜의 명시적 입력 허용 동작은 유지한다.
- 저장은 useAttendance.saveAttendanceRange를 통한다. 기간 전체의 기존 기록을 조회하고, 겹치는 날짜가 있으면 UI에서 변경을 확인받는다. 단일 INSERT 또는 UPSERT로 부분 저장을 방지한다.
- 수정 시 기존 NEIS 입력·증빙서류 체크 상태를 보존한다. 인증과 RLS, 학생당 하루 한 기록 모델은 변경하지 않는다.
- 저장 후 당일 목록·집계·달력을 갱신하고, 입력창의 학생 선택과 메모를 초기화해 다음 학생을 입력한다. 출석으로 복구할 때는 기존 삭제 확인창과 clearEntry를 사용한다.
- 검증: 날짜 범위·하루 입력·기존 기록 확인·저장 실패·월 경계 훅 테스트, 화면 회귀 테스트, build/lint, 샘플 데이터 브라우저 점검.
