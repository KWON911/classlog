# 개인별 출결 이력 UI 통일 설계

## 목표

출결관리의 개인별 이력을 월간 요약과 같은 카드, 상태 뱃지, 버튼 필터 및 이력 행 밀도로 표시한다.

## 동작

- 학생 선택 드롭다운은 유지한다.
- 상태 필터는 드롭다운 대신 `전체`, `결석`, `지각`, `조퇴`, `결과` 버튼 그룹으로 바꾼다.
- 학생 선택 후 카드 헤더에 번호·이름과 전체 누적 상태별 건수를 월간 요약과 같은 뱃지로 표시한다.
- 이력 행은 월간 요약과 동일하게 날짜, 상태 뱃지, 사유, 메모를 한 줄 우선으로 표시한다.
- 개인별 이력은 조회 화면이다. 월간 요약의 삭제·NEIS·증빙서류 관리 버튼은 추가하지 않는다.

## 구조

- 월간 요약과 개인별 이력은 같은 상태 색상 상수와 공통 상태 뱃지 컴포넌트를 사용한다.
- `useAttendanceSummary`를 개인별 이력의 전체 누적 뱃지 데이터에 재사용한다. 상태 필터는 이력 목록 조회에만 적용한다.
