# 정보관리 학생목록 밀도 개선 설계

## 목표

정보관리의 학생 정보 목록에서 같은 화면에 더 많은 학생을 표시하되, 교사가 필요한 학생을 식별하고 상세·수정·삭제 메뉴를 누르는 흐름은 유지한다.

## 선택한 방향: A형 압축 명단

- 카드 내부의 학생 정보 헤더를 한 줄 우선 레이아웃으로 만든다. 제목, 인원, 성별 요약은 왼쪽에, CSV와 추가 작업은 오른쪽에 둔다. 화면 폭이 부족하면 기존처럼 자연스럽게 다음 줄로 감싼다.
- 데스크톱 학생 행 높이는 54px에서 44px로 줄이고, 목록 시작 전 여백과 헤더 하단 여백도 줄인다.
- 데스크톱 그리드는 번호 52px, 이름 가변, 성별 64px, 관리 36px로 조정한다. 이름 열은 남은 폭을 계속 사용한다.
- 모바일은 현재 52px 행 높이와 36px 메뉴 버튼을 유지해 터치 접근성을 낮추지 않는다.
- CSV 가져오기·내보내기, 개별 추가, 상세정보 보기·수정·삭제, 로딩·빈 상태·오류 상태, 데이터 흐름은 변경하지 않는다.

## 검증

- 목록에 기존 제어 버튼과 학생 정보가 계속 렌더되는 컴포넌트 테스트를 유지한다.
- `npm test`의 알려진 자리배치 시간 초과와 별개로 변경 대상 테스트, lint, production build를 실행한다.
- 데스크톱과 iPad 폭에서 헤더 줄바꿈 및 관리 메뉴의 접근성을 수동 확인한다.
