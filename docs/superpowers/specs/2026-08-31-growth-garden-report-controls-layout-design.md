# 성장정원 월별 리포트 제어부 배치 디자인

## 배경

월별 리포트 상단에서 페이지 이동, 리포트 종류, 월 선택이 한 줄에 섞여 있다. 월별 데이터를 먼저 고른 뒤 학급 또는 개인 보기를 고르는 작업 순서가 화면 구조에 드러나지 않는다.

## 목표

- 페이지 이동 탭은 첫째 줄에 단독으로 둔다.
- 월 선택은 둘째 줄의 첫 번째 컨트롤로 둔다.
- 학급/개인 탭은 월 선택 오른쪽에 둔다.
- 화면 크기와 관계없이 이 두 행의 순서를 유지한다.
- 선택 월, 리포트 탭, 접근성 라벨, 월 변경 동작은 바꾸지 않는다.

## 레이아웃

```text
[정원 | 월별 리포트 | 설정]
[2026년 8월 선택] [학급 | 개인]
```

첫째 줄은 성장정원 안에서 이동할 화면을 고른다. 둘째 줄은 현재 보고 싶은 기간을 먼저 선택한 다음, 그 기간의 학급 또는 개인 데이터를 고른다.

## 구현 방향

`GrowthGardenReportPage`의 기존 제어부를 두 개의 flex 행으로 나눈다. 첫째 행에는 `GardenPageNav`만 렌더링하고, 둘째 행에는 `MonthSelector` 다음 `SegmentedGroup` 순서로 렌더링한다. 상태와 이벤트 핸들러는 현재 props를 그대로 사용한다.

## 검증

- 리포트 화면에서 페이지 이동 탭이 첫째 줄에 단독으로 보이는지 확인한다.
- 둘째 줄에서 월 선택이 학급/개인 탭보다 왼쪽에 보이는지 확인한다.
- 이전/다음 달, 월 선택 팝오버, 학급/개인 전환이 기존처럼 동작하는지 확인한다.
- 프로덕션 빌드, 린트, 전체 테스트를 실행한다.

## 범위 제외

- 월 선택기, 리포트 종류 탭의 문구·색상·크기 변경
- 리포트 데이터 집계, 보상, 수상 기능 변경
- 다른 성장정원 화면의 툴바 재배치
